# job-for-all-demo
Jobs For All (Demo) is an inclusive employment platform designed to connect
persons with disabilities with suitable employment opportunities.

## Demo

This repository contains a demonstration/prototype version of the
Jobs For All platform for presentation and evaluation purposes.
